How this is written, and how it is checked

The short version, because you should not have to read a verification log to decide whether to trust a page about a kitchen appliance.

  1. Read the listing. Capacity, dimensions, materials, what the maker names as dishwasher-safe. Title, brand and category path. Nothing is typed from memory.
  2. Link the row. Every value on this site sits in a table row whose last cell links the official page it was read from. If a row has no source, the build fails.
  3. Leave the gap visible. If a listing is silent - a cleaning claim, a capacity unit, a function count that disagrees with itself - the gap is printed and flagged rather than smoothed over (all open items).
  4. Do not publish what the rules forbid. No prices, no star ratings, no price history, no popularity claims. Each of those has a cited rule behind it on the policy page.

The full audit trail - every source, every flag, every correction - is in the page index at the bottom of every page. Start with the verification log if that is what you came for.
