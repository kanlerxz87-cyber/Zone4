Four questions that settle it

The buying guide is built around these, in this order. They are answerable from the listings without a single published price.

Pick the format

Dual basket, single basket or a French-door toaster oven. This choice decides everything else, and it is the one the listings cannot make for you.

Carry the unit

The listings disagree with themselves: a title says 6 quart while the details table says 6 liters. Both are shown as written, never converted.

Measure the counter

All three listed footprints are published exactly as the seller wrote them, so the tape measure happens before the checkout.

Read the small print
