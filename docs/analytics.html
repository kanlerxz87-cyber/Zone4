Rows in the ledger: 0 — No Associates account or reporting feed is connected (Q-01, Q-48, F-19), so no authorized figure exists to put in a row. The ledger is defined now so that measurement, when it arrives, lands in one agreed shape. A row without a named first-party report, a report period and a retrieval date is invalid. Figures are copied exactly as the report states them; nothing is estimated, interpolated, modelled or forecast. A later report that revises an earlier figure is added as a new row with its own provenance, never by editing the old row.

The self-hosted analytics endpoint

Contract published; endpoint not deployed. GitHub Pages serves static files only and cannot host a POST endpoint (F-56). Hosting is an owner decision (D-40).

docs/tracker.js reads an endpoint URL from the <meta name="analytics-endpoint"> tag. While that tag is empty (as it is today) the tracker is local-only and sends nothing anywhere. When an endpoint is configured, each of the five defined events is POSTed as one JSON object and the local copy stays available.

POST, application/json — fields: event (one of EV-1..EV-5), ts_utc (ISO 8601), path (site path only), target (outbound URL for EV-1/EV-5, empty otherwise), asin (for EV-1, empty otherwise)

  • No cookies, no cross-site identifiers, no fingerprinting, no third-party pixels.
  • No IP address is stored or forwarded; referrers are not collected.
  • A consent notice appropriate to the audience must be published before the endpoint is enabled (Q-14, Q-17, D-16).
  • The labelled test event is never sent to the endpoint; it exists only for the local mechanism check.

Participation Requirement 6(s) (no artificial or fraudulent activity) and Commission Income Statement reporting terms; the privacy review is an owner decision (D-16)

Connecting real measurement

  • Join the Amazon Associates Program and receive an Associates ID, then use the tagged Special Link formats (see Policy compliance).
  • Confirm the tag on the supplied short links before relying on any earnings (see F-03).
  • Authoritative click, order and commission figures come from the official Associates Central reporting.
  • Product data served from Amazon must come through the Creators API, and reusing or fine-tuning on API content needs express prior written approval (see F-24).
  • Price tracking and price alerting are prohibited unless Amazon agrees otherwise, so no price history is collected here (see F-22).
  • Add a cookie or consent notice appropriate to your audience before enabling measurement on real traffic, consistent with the disclosure expectations in the official Program Policies and applicable law.
