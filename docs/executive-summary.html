Executive summary

Three user-supplied Amazon links resolve to three verified air-fryer product pages. Every published figure was read again from the official Amazon page on 2026-11-14. Prices, ratings, commission rates and trend data are not published, because they could not be verified or the Associates policy does not allow them on this site. The marketing content the brief asks for is built from those verified figures only.

What the verification found

  • Identity verified and re-verified: each link resolves to an Amazon product page (ASINs B0CDY277D3, B09B7SB46R, B08DKYBTPH). All three sit under the same Amazon category path (Home & Kitchen > Kitchen & Dining > Small Appliances > Fryers > Air Fryers). The listing titles, brand bylines, category breadcrumbs and the complete specification tables were read again on 2026-11-14 and every value matches. Flag F-04 covers the short-link codes.
  • Marketing content is built: three product articles, one comparison page and one buying guide, each with a title tag, meta description, keyword targets, an outline, finished copy, a call to action and a fact table in which every row links to its official source. Copy is written in this site's own words and republishes no Amazon listing prose (F-12).
  • Pricing and ratings withheld: the Associates Participation Requirements (Section 2(b) for prices and availability, Section 6(t) for star ratings and customer reviews) allow those figures on a site only through Amazon-served links or Creators API / PA API. The pages were read, but no price, rating or review count is published (F-02).
  • Commission potential not calculable: the category commission schedule is behind an Amazon sign-in, so no rate is entered (F-01). Third-party sources conflict on the Kitchen rate, so they are listed as non-official references and are not used as data.
  • Attribution unverified: the resolved links carry no Associates tag parameter (F-03). Confirm the links were generated under your Associates ID before relying on any earnings.
  • The automation and tracking plan is built and specified, with every metric left blank: a first-party, local-only click tracker is implemented and starts at zero (Analytics page), but click-to-order attribution, unit-session and revenue reporting need Associates reporting and a tagged link (F-19); price tracking is prohibited by default (F-22); API reuse and model training need prior written approval (F-24).
  • Agent Terms apply to the research agent in the brief: any agent that touches Program Content must identify itself as 'Agent/[name]' in the user agent string, must not conceal that it is an agent, and must not solve CAPTCHAs or work around access limits (F-21).
  • Compliance: the required disclosure sentence appears on every page (R-01). Open legal items: the Conditions of Use limit collecting listing content and using robots for extraction (F-11), and Amazon Marks must not be used as search keywords (F-23).
  • Site: static GitHub Pages site; the repository root redirects to the site in docs/. Every table row links to an official source, and unverified values are blank and flagged.
  • Measured, not modelled: the Analytics page records real clicks in the visitor's own browser and exports them as JSON or CSV. It sends nothing to any server, it never invents a figure, and the only non-click event it can write is one explicitly labelled a test. The tracked links are the supplied short links, which still carry no visible Associates tag, so a recorded click cannot yet be reconciled against Amazon reporting.

Not built, and why

  • Conversion, order, unit-session and revenue attribution (needs Associates reporting and a tagged link). The Analytics page records first-party clicks locally and publishes no attributed figure. Flag F-19.
  • Automated product research at scale (needs a compliance decision under the Agent Terms, and Creators API access rather than page retrieval). Flags F-11, F-21.
  • Price, rating and review analysis on the public site (withheld under 2(b) and 6(t), and price tracking is prohibited by default). Flags F-02, F-22.
  • Commission calculations and earnings projections (needs the category rate from the signed-in schedule). Flag F-01.
  • API integration of any kind, including reusing or fine-tuning on API content (needs express prior written approval). Flags F-16, F-24, F-25.
  • Price tracking, price alerting and cross-retailer price comparison (restricted by 6(y) and 6(z)). Flag F-22.
  • Email or outreach campaigns carrying Special Links (would need to be opt-in only, and Program Content must stay out of offline material). Flag F-27.
  • Campaign optimisation (needs the attributed data above; the loop itself is specified on the Automation page).
