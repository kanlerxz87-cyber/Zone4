What the statuses mean

  • Delivered - Working on the published site now.
  • Delivered (partial) - Something is published, but a named part of the requirement is missing or unverified.
  • Not built - blocked (policy) - Building it as described would breach a rule that is cited in the Blocker / official rule column. Not attempted.
  • Not built - needs access - Not blocked by policy, but needs an Associates account, an API key or reporting data this repository does not have.
  • Unverifiable (blank + flagged) - No official source provides the value. The field is left blank on the site and flagged for review.
