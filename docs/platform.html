Platform & automation

The brief describes an AI platform. This repository is the data-driven research and content layer of that platform, built so that each stage can be automated only once its gate clears: a data source for research, a rate source for earnings, an account for links, and a compliance decision for automated generation. Nothing is faked to look automated.

Guardrails built into the pipeline

  • verify.py fails the build if any table row lacks an official-host link, so a source-free claim cannot ship.
  • verify.py fails if any price string or star-rating string appears on any page, enforcing R-02 and R-03 mechanically.
  • verify.py fails if the disclosure sentence is missing from any page, enforcing R-01.
  • verify.py fails if marketing copy claims a personal test or trial of a product, enforcing R-26.
  • External links are restricted to an allow-list of official hosts, so third-party stats cannot creep in.
  • The build is deterministic from data/*.json, and CI rebuilds it and diffs the result, so the published site always matches the reviewed data.

These checks live in the build itself (scripts/verify.py) and run in CI on every push and pull request.

Scalability

Product records are data, so the site scales by rows: a new product adds one object to data/products.json and gains a table row, a verification block, a category entry and a content draft automatically. The scaling limit is verified data, not the site.

Not connected in this environment

  • Amazon Associates account or API keys
  • PA-API or Creators API access
  • Analytics or search console property
  • Content management or email system
  • Any paid promotion channel

Niche selection method

A profitable-niche ranking needs demand and earnings inputs. Neither is available from an official source in this environment, so the table publishes the method and the qualitative observations, and leaves the numeric columns blank rather than estimating them.

  1. Start from the category Amazon assigns to the products, not from a guessed topic.
  2. List the competing products Amazon itself shows beside each listing, and note whether that module is sponsored.
  3. Score each candidate niche on demand, competition, ticket size, commission rate and content angle.
  4. Leave an input blank when no official source supplies it, and record why on the Flagged page.
  5. Re-score only when a data source changes, for example after PA-API access is granted.
