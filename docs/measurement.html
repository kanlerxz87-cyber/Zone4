Five site-side counters

DNT and Global Privacy Control stop the sender. Requests omit credentials and Referer; payloads contain only known public page paths, category paths and catalog ASINs. The application stores daily aggregates, not visitor identifiers. Hosts, proxies and network services still receive connection metadata: their logging needs a separate review, and GitHub documents security IP logging for Pages.

Retention: Staged maximum: 30 UTC day buckets, including today. Pruned on writes, startup and hourly while the reference collector runs. Backups and host logs require a separate reviewed deletion policy before launch.

These are best-effort event counts, not unique people, sessions, search queries, confirmed Amazon clicks or orders. Ad blockers, opt-outs and delivery failures mean totals can be incomplete; a caller can also spoof an Origin header. Do not optimize for sales from these counters alone.
